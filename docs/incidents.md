# Incidents

A short note for anything users noticed: an outage, wrong data, a leaked secret. Newest first.
It shows repeat problems and gives DAX a record if they ask.

Copy this for each entry:

```
## YYYY-MM-DD: <what broke, in a few words>

- What happened: <what users saw, from when to when>
- Cause: <why it happened>
- Fixed by: <what was changed>
- Follow-up: <anything still to do, or "none">
```
